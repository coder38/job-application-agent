# Resume standards

Part of the job-application-agent skill. Read this before drafting any tailored resume.

Drawn from widely used resume and recruiter guidance.

- **Bullets show results, not duties.** Use the accomplishment formula (Google's "XYZ": accomplished X, as measured by Y, by doing Z): strong action verb + what you did + how (tools, platforms, methods) + measurable result. For example, "Built 40+ Epic Ambulatory order sets and SmartPhrases with clinical leads, cutting provider documentation time by 15%" rather than "Responsible for building order sets." Where a bullet has no real result to measure, keep it a crisp action-and-scope line rather than padding it to fit the formula.
- **Quantify with real numbers only:** users, volume, time saved, money, accuracy, uptime, scale, team size. If the user has no number, show scope instead (how many sites, systems, users, or releases). Never estimate or invent a metric, and never put "realistic" placeholder numbers in a draft.
- **Find the real numbers.** Before drafting, ask once whether the user has material that holds more detail than the resume: performance reviews, project write-ups or case studies, demo notes, or award announcements. These often hold real metrics and achievements the resume left out. Use only facts they state; leave out confidential code, internal data, scores, and other people's names. In the draft, list the bullets where a real number would help most and ask for it; if the user wants to fill them in later, mark them `[FILL IN]` and never let a marker reach the exported file.
- **Most relevant and highest impact first.** Order bullets within each role by relevance to the posting, then by impact. Aim for 3-6 bullets for recent roles and 1-3 for older ones, each 1-2 lines. When a role has many bullets, group them under short subheads (for example "AI & Automation" and "Platform & Delivery") so the most relevant group comes first.
- **Summary:** three sentences, about 3-5 lines: (1) professional identity with years of experience and setting; (2) one or two quantified signature achievements, stated as outcomes rather than copied from the bullets; (3) the value the user brings to this target role. No availability or logistics lines, no generic filler, no awards that read as bragging (put those in the role instead), and don't repeat certifications already listed under Certifications.
- **Headline and titles:** a headline under the name may describe the user's function (for example "Senior Software Engineer | Guidewire InsuranceNow") when it truthfully reflects their work, but job titles under Experience must match the user's official titles exactly. If the two differ, give the user one line they can use in an interview to explain it.
- **Interview-defensible:** list only skills, tools, and libraries the user can explain in an interview. If an AI tool chose the libraries behind something the user built, credit the work ("built with Claude Code") rather than listing those libraries as skills.
- **No repetition:** vary the opening verbs across bullets, merge bullets that describe the same work, and state each fact once.
- **Skills and certifications:** group skills by type (platforms and modules, languages, tools, methods) and use the posting's exact terms where the user truly has the skill. List certifications by their exact official names with status (for example "Epic Ambulatory certified" vs "Epic Ambulatory proficiency"); never upgrade a status.
- **Style:** no first-person pronouns; present tense for the current role and past tense for earlier ones; consistent date format; abbreviations spelled out once where a recruiter might not know them.
- **Cut filler.** Remove: "responsible for", "duties included", "worked on", "helped with", "assisted in", "involved in", "various", "a variety of", "successfully", "effectively", "etc.", "in order to" (use "to"), "utilize" (use "use"), and self-descriptions such as "hardworking", "team player", "detail-oriented", "results-driven", "dynamic", "passionate", "proven track record", and "go-getter". Also avoid hype words such as "revolutionized", "spearheaded", "synergy", "rockstar". Show these qualities through results instead.
- **ATS-friendly format:** standard section headings (Summary, Experience, Skills, Education, Certifications), a single-column layout, no text in tables, images, headers, or footers, standard fonts, and the posting's keywords used naturally, never stuffed.
- **Before showing the draft,** reread every line and cut any word that doesn't add information.
